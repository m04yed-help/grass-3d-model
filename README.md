# 🌱 Grass 3D Model

A lightweight, low-poly grass asset made in Blender, exported for use in game engines and other 3D pipelines.

## 📦 What's included

| File | Description |
|---|---|
| `Untitled.blend` | 🧩 Source Blender scene |
| `Untitled.fbx` | 🎮 FBX export (Unity, Unreal, etc.) |
| `Untitled.glb` | 🌐 glTF binary export (web, three.js, Godot, etc.) |

## 🔍 Details

- 🌾 24 grass blade/tuft meshes (plane-based "grass cards")
- 🎨 Single shared material
- 📷 Camera and lighting set up for preview renders in the `.blend` file

## 🚀 Usage

Import `Untitled.glb` or `Untitled.fbx` into your engine of choice, or open `Untitled.blend` directly in Blender to edit the source scene.
